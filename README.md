# Stochastic Cancer Evolution: Wright–Fisher Simulation
Computational Biomedicine, Tutorial 4 (part 1). Neutral stochastic population model for four population sizes and four initial cancer-cell proportions, using 50 replicates across 100 generations. R and ggplot2.

## Run
Run `Rscript analysis.R`. This extracted portion of the recovered Tutorial 4 script is self-contained; no empirical data required. It writes simulated trajectories and summary statistics. R was not available to retest this extraction; verify locally before publishing. Check course permission.
